# Customer Web images

Drop the real images here with these exact filenames; the page picks them up automatically.

| File | Used for | Recommended |
|---|---|---|
| `logo.webp` | Header logo (already in place) | Replace with a vector/transparent version when available |
| `hero-highway.jpg` | Hero background photo (highway / driver / sunset) | 2400 × 1000 px or larger, landscape, JPG |
| `food-burger.jpg` | "Burger Hub" card in the hero | 600 × 400 px, JPG |
| `food-pizza.jpg` | "Pizza Point" card in the hero | 600 × 400 px, JPG |

Until the food images exist the cards show an emoji placeholder; until the hero photo exists a warm gradient is shown.
